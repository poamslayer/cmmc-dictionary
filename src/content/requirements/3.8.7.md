## Requirement

"Control the use of removable media on system components."

## Objectives

[a] the use of removable media on system components is controlled.

## Sufficient

- **Hardware-encrypted drives issued only to users with a documented business need, combined with an endpoint detection and response tool that controls which drives may connect and audits what files move to and from each one.** Practitioner consensus treats the pairing of issuance-by-need and technical enforcement as sufficient, since the policy limit and the technical control reinforce each other. [a]
- **A locking bezel on hot-swappable server drive bays**, serving as the physical control that prevents unauthorized use of drives that would otherwise be removable without tools. [a]

## Insufficient

No documented position beyond the Assessment Guide; see confidence.

## Over-engineering

No documented position beyond the Assessment Guide; see confidence.

## Edge cases

- **Whether hot-swappable server drives count as "removable media" for this requirement.** Federal guidance on non-removable storage limits that category to storage accessible only by removing an enclosure panel or using hand tools; a hot-swap drive removable without tools falls outside that narrow exemption and reads as removable media by that standard, though a locking bezel on the drive bay can serve as the control that satisfies the requirement for it.

## Evidence examples

- **Policy document** defining which removable media types are authorized. [a]
- **Endpoint control configuration** showing device-connection rules for removable media. [a]
- **Audit log** recording file transfers to and from removable media devices. [a]
- **Issuance list** naming encrypted drives assigned to specific users with a stated business need. [a]
- **Locking bezel documentation** for server drive bays holding hot-swappable drives. [a]

## Related requirements

- **3.8.8** builds on this requirement by also requiring an identifiable owner for portable storage devices, even ones of an otherwise-allowed type.
- **3.8.6** governs the encryption of CUI stored on removable media once its use is controlled here.
- **3.4.8** controls what software may execute; this requirement controls what removable media may connect in the first place.
