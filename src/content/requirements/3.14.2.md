## Requirement

"Provide protection from malicious code at appropriate locations within organizational information systems."

## Objectives

[a] designated locations for malicious code protection are identified; and
[b] protection from malicious code at designated locations is provided.

## Sufficient

- **Endpoint protection on every workstation and server operating system, combined with gateway-level antivirus at managed network interfaces such as the WAN edge.** Practitioner consensus describes this pairing as the baseline footprint that satisfies both objectives together. [a][b]
- **Installing anti-malware software as part of standard computer setup.** Assessment Guide example treats buying and installing anti-malware protection on a new machine as covering both the identification of a designated location and the delivery of protection there. [a][b]

## Insufficient

No documented position beyond the Assessment Guide; see confidence.

## Over-engineering

No documented position beyond the Assessment Guide; see confidence.

## Edge cases

- **Whether protection must extend past traditional endpoints to servers, network devices, mobile phones, and containerized environments, or whether the endpoint-plus-gateway footprint already covers the requirement, was raised without a settled answer.** Practitioner discussion pointed to the classic footprint as the expected baseline but did not resolve whether it is sufficient on its own for every environment; the outcome depends on the assessor.

## Evidence examples

- **A documented list of designated locations** (workstations, servers, gateways, mobile devices) where malicious code protection applies. [a]
- **Installed anti-malware software configuration** on endpoint devices. [b]
- **Gateway-level antivirus or content filtering configuration** at a network boundary point. [b]

## Related requirements

- **3.14.4** requires the protection mechanisms this requirement establishes to be kept updated when new releases become available.
- **3.14.5** requires periodic and real-time scanning using the same malicious code protection mechanisms named here.
- **3.13.1** and boundary protection define the network perimeter where gateway-level protection under this requirement is typically placed.
