## Requirement

"Check media containing diagnostic and test programs for malicious code before the media are used in organizational systems."

## Objectives

[a] media containing diagnostic and test programs are checked for malicious code before being used in organizational systems that process, store, or transmit CUI.

## Sufficient

- **Real-time malicious-code protection running on the system that will receive diagnostic or test media, kept current and actively scanning, has been accepted as satisfying this requirement.** A dedicated separate scanning machine is a stronger option but is not required to reach a MET finding for most organizations of typical size. [a]
- **Checking whether a maintenance technician's own laptop or removable media has active, updated protection is a common and accepted way to evaluate this objective.** The reasoning is that current malicious-code protection scanning the local disk will also scan removable media as it is connected. [a]
- **A standalone, restricted device used specifically to scan removable media before it is permitted to connect to the environment that processes CUI satisfies the "before use" element.** Scanning happens on a device that never itself touches the protected environment, which makes the sequencing unambiguous. [a]

## Insufficient

- **Relying on an automatic scan that begins when media is inserted while still allowing the media to be used during that scan.** This does not clearly satisfy an objective that specifies checking occurs before use; a scan that completes, or a scanning step performed on a separate device, before the media connects to the protected environment more clearly reaches the "before" element. [a]
- **Confirming a technician's protection status once, at the start of an engagement, and treating that as good for every later visit.** The objective is about the media being checked at the point it is used; a status confirmed weeks or months earlier does not establish that the protection was current and active on the day the media was actually connected. [a]

## Over-engineering

- **A dedicated air-gapped scanning workstation, of the kind used in classified environments, in a typical unclassified CUI environment that already runs current malicious-code protection with real-time and automatic removable-media scanning.** The air-gapped approach adds cost without adding assurance the existing protection does not already provide. [a]

## Edge cases

- **Whether "media" reaches beyond physical items like removable drives and optical disks to cover anything obtained from the internet is a definitional question.** The federal glossary definition of media is limited to physical devices and writing surfaces, and the system's ongoing malicious-code protection is already expected to scan files pulled in from a network connection as they arrive, so this objective is best read as targeting physical items carried in for maintenance work rather than content obtained online.

## Evidence examples

- **Endpoint protection configuration showing real-time scanning and automatic removable-media scanning enabled.** [a]
- **Maintenance technician device inspection record or attestation of current protection status.** [a]
- **Standalone scanning station configuration or usage log, where one is used.** [a]
- **Policy documenting the media-scanning step required before diagnostic or test media is connected.** [a]
- **A dated record or attestation tied to the specific maintenance visit, rather than a one-time confirmation made when a technician relationship began.** [a]

## Related requirements

- **3.14.2** and **3.14.4** malicious code protection requirements provide the underlying scanning capability this requirement extends specifically to diagnostic and test media.
- **3.7.1** and **3.7.2** the maintenance activity and its tool controls that this requirement's media check supports.
